Migration 27 protects all original PDFs and limits original access to project managers/PocketBase administrators. The frontend downloads the authorized excerpt with its auth header and renders local pages with original page labels. Preserve native page rotation; provide PDF.js CMaps and standard fonts. Verify file-token bypass attempts, anonymous/other-user/released/expired access, last-page behavior, extracted page count/content/watermark and browser rendering. Rollback reopens originals and must be treated as a security rollback.

## Deployment and verification
Original files remain unchanged in storage. Apply migration 27 before serving the new frontend; old frontends that request raw public file URLs will receive 403. Project managers and PocketBase administrators can still retrieve originals using authorized protected-file tokens. New excerpts are generated per authorized request, with `private, no-store`, and are not stored in public file collections. Previously downloaded copies cannot be revoked; purge any independently configured public CDN cache of original PDFs when deploying this access change.

Verified with a four-page test PDF containing page-specific text, borders, standard-font text and a rotated page: the two-page excerpt preserves the visible page dimensions, contains only selected-page text and an embedded user/task/time watermark; EOF returns one page. Browser tests inspect actual canvas pixels and downloaded PDF text. User's original problem PDF was not available for a page-by-page comparison.
