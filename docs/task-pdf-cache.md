# 校对 PDF 私有缓存

任务预览仍只分发任务页和后一页，末页只分发一页。Nginx CSP 的 `connect-src`
允许 `blob:`，供 PDF.js 读取已通过身份校验下载的 PDF。

上传校验阶段串行预切单页，旧文件在首次访问时补建。缓存位于
`pb_data/pdf-preview-cache-v1`（目录 0700、文件 0600），不属于公开文件 API。
按文件版本复用单页，按用户、任务、页码和文件版本复用带服务端水印的预览。
水印含用户/任务 ID 和生成时间，5 分钟内重用；每次请求仍检查当前项目权限、
任务归属和租约，缓存命中不延长授权。响应始终为 `private, no-store`。

带水印文件 5 分钟过期，单页缓存 24 小时过期，每分钟清理；下次启动后的清理
也处理遗留文件。总缓存预算 1 GiB，单书展开上限 256 MiB，空间不足时淘汰最旧项。
共享资源展开过大或缓存写入失败时退回原来的按需两页生成；PDF 原件不受影响。
展开超限的文件版本会记忆 24 小时，避免每个新任务重复执行整书预切。
因此冷启动/首次预切仍消耗 CPU，缓存命中可避免重复解析整本书和重复加水印，
不能把它视为所有负载下的固定 CPU 性能保证。当前为单 PocketBase 进程缓存。

无需数据库迁移，随镜像更新启用。回滚旧镜像后可删除整个缓存目录以回收空间。
